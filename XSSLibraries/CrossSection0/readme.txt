光子と物質との相互作用断面積データ検索  Xcom_V3_3

【動作環境】
　Microsoft Visual Basic(Version 6.0) 動作環境 (MSVBVM60.DLL等が必要です）

【配布ファイル】

【使用方法】
　エクスプローラ等から Xcom_V3_3.exe を起動して下さい。
　元素または化合物／混合物を選択し、OKボタンを押すと、
　相互作用断面積データの一覧表およびグラフが表示されます。
　
　右下のテキストボックスに任意の光子エネルギーを入力し、Enterキーを押すと、
　それに対応する各相互作用断面積および質量減弱係数が表示されます。
　同様に、任意の質量減弱係数を入力し、Enterキーを押すと、
　それに対応する光子エネルギーおよび各相互作用断面積が表示されます。

　新機能(2009-01)
　・グラフをイメージデータ(BMP形式)として保存可能とした。
　・化合物，混合物のデータを新規に作成可能とした。
　・データをエクセルCSV形式で再保存可能とした。

　(2011-03)
　・混合物データ新規作成において、含有元素数の最大値を15とした。
